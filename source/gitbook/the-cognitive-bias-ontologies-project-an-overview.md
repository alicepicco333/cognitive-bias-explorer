# The Cognitive Bias Ontologies project: an overview

A brief introduction of the project developed as part of KRKE course held by Professor Aldo Gangemi in the academic year 2022/2023.

The KRKE project aimed to create a collective ontology that would collect and describe the many biases that affect human beings. Given the large number of these biases, several groups were formed within the class of students in the KRKE course to work on the various clusters of biases and develop dedicated ontologies for each of them. The project  was characterized by certain aspects that are described in the following sections:
